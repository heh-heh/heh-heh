# 문제정의 / 설계 경계 / 성공 조건 (Draft PRD v0.1)

## 제품 비전

V0.9는 **공통 주문장, 가격·시간 우선순위, 외부 유동성 및 자본 위험**이라는 동일한 제약 아래서 서로 다른 유전형 전략 AI들이 주문을 내고 체결 경쟁을 하며, 유효한 5회 거래 세션 뒤 자연선택·교차·돌연변이를 겪는 인공 주식시장 연구 플랫폼입니다.

게임적인 경쟁 구조를 갖되, 연구 대상은 가상 수익률이 아닌 **독립 데이터에서의 일반화와 실행 가능성**입니다.

## 먼저 해결해야 할 네 가지 설계 선택

1. **데이터-내생적 가격 충돌** — 과거 가격 리플레이에 봇 주문 충격을 추가하면 실제 호가와 시간축이 충돌할 수 있음. `관측 기반 리플레이`, `모형 기반 가상시장`, `혼합시장`을 각각 평가할 것.
2. **거래가 안 되는 시장** — 50~1,000개 학습 봇끼리만 있으므로 매수·매도 균형이 깨질 수 있음. 시장조성자·비학습 외생 주문흐름을 구성하되 외생 유동성의 무제한 수익 보장은 금지.
3. **경쟁과 유의미한 성과의 구분** — 내부 상대순위만 높거나 극단적 위험을 쓴 봇은 성공이 아님. 수수료·시장충격 순손익과 독립 검증을 동시 사용.
4. **실행 시간 의미** — 16h/8h는 *가상 시뮬레이션 시간·워크플로 정의*인지 실제 벽시계 시간인지 구분. 처음에는 결정론적 가속 이벤트 시뮬레이션을 기본안으로 검토.

## MVP / 이후 목표

**MVP:** 50~100 봇 · 1~3종목 · 결정론적 주문 이벤트 및 부분체결 · 가상 장부 · 외생 유동성 · 전략 4종 · 5회 세션 결과 · 교차/변이 · 재생 가능한 거래 로그 · 정적 대시보드.  
**확장:** 250~1,000+ 봇 · 다양한 주식·레버리지 리스크 · 적응형 시장조성자 · 이벤트 스트림 · 병렬 계산 · 통계적 검증.  
**비범위:** 승인 없는 실제 금융 주문, 입증되지 않은 수익 보장, 금융 인허가를 대신하는 법률 결론, 단일 결과의 과대 홍보.

## 최초 합격 기준

- 주문 총량·체결량·포지션·현금의 **장부 불변식** 위반 0건.
- 동일 seed / 동일 입력에서 체결, 포지션 및 진화 결과가 정확히 재현됨.
- 서로 다른 주문 제출 순서가 **의도대로** 체결 우선순위에 반영됨.
- 미완료/누락 데이터는 신호·부모 선발에서 제외됨.
- 모든 세대의 독립 평가군과 부트스트랩/반복 seed 불확실성 기록.
- 로컬 PC의 처리량 목표는 10월 26일 실제 하드웨어 벤치마크 후 수치 확정.
- 수익률·유의성은 **미입증**. 관전성과 최적화도 이와 구분.
