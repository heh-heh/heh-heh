# Round 0 · 초기 반증 과제 (단일 작성자 초안)

> **중요:** 이 문서는 12개 LLM을 실행해 얻은 독립 심사 결과가 아닙니다. 12개 전문팀이 실제 독립 제안에서 검토해야 할 문제를 사전등록한 **공통 챌린지 목록**입니다.

| 담당 관점 | 미확정 주장·반례 | 독립적으로 증명할 방법 | 심각도 초안 |
|---|---|---|---|
| T01 거래소 | 시장가 주문을 무한 유동성에 체결하면 허위 우승 | 깊이 3레벨 부분체결+수량 보존 테스트 | Critical |
| T02 진화 | 5세션 승자가 장기적으로 좋은 유전자라는 가정 | 20+ seeds × 서로 다른 레짐 재현, diversity curve | High |
| T03 퀀트 | 레버리지 ETF를 종목 수 1개로만 계산 | 위험노출(실질 gross)·현금·손절 예산 불변식 | High |
| T04 통계 | 반복 생존 선발이 p-value를 왜곡 | 고정 평가 프로토콜, 공정 기준전략·신뢰구간 | High |
| T05 데이터 | t분에 완료된 봉이 t분 체결에 동시에 사용 | 신호 시각/다음 관측 체결 테스트 | Critical |
| T06 성능 | 봇 1,000개가 2배 CPU로 해결 | 이벤트 수·호가 갱신량·메모리 상한 사전 실측 | High |
| T07 합성시장 | 실제 가격 리플레이와 내생 충격을 동시에 적용 | 불변식/외부 유동성 보정 실험, 시장 통계 일치 검증 | Critical |
| T08 보안 | 봇이 자기 주문과 거래하고 이익을 창출 | 자기체결 차단, 담합 시뮬레이션, 권한 경계 | Critical |
| T09 관제 | 부모의 누적 손익을 새 자식의 실현 성과로 표시 | UI E2E fixture로 평가 전 자식 수익 미표시 | High |
| T10 게임 | 매 거래를 강제하면 거래비용 패널티가 왜곡 | WAIT 봇 vs 강제거래 봇 대조군 실험 | High |
| T11 신뢰성 | 체크포인트 재개 시 중복 주문 체결 | 이벤트 ID 멱등성, 프로세스 크래시 20지점 | Critical |
| T12 비용 | 자가PC 성능·유지비 없는 4주 완성 확언 | 하드웨어 사양 실측, 단계별 실제 공수 추정 | Medium |

## 서로 충돌하는 초기 설계 대안

**가격 형성:** 실제 이력 가격 고정 vs 내생적 청산 가격 vs 혼합모형.  
**유동성:** 규칙형 시장조성자 vs 학습 시장조성자 vs 주문 데이터 리플레이.  
**진화:** 모든 수익 봇 부모 풀 vs 상위 2명 강제 생존 vs 다목적 위험조정 선발.  
**시간:** 벽시계 16h/8h vs 24h 논리 시뮬레이션의 가속 재생.  
**공정성:** 모든 봇 동일 데이터·자본 vs 다양한 성향에 맞는 위험 예산과 주문 한도.

이 목록은 결론이 아니며, 각 안의 반증 가능 실험과 장부·데이터 계약이 확보되기 전까지 ADR에서 결정을 유보합니다.
